# Крестики-нолики (TicTacToe)

Игра для двух игроков на Windows Forms (C#). Сделана по методичке «Создание игры Крестики-Нолики».

## Как запустить

1. Распакуйте архив (правой кнопкой → **Извлечь всё**).
2. В Visual Studio: **Файл → Открыть → Проект или решение** → выберите `TicTacToe/TicTacToe.csproj`.
3. Нажмите **F5**.

Нужны Visual Studio 2022 с компонентом «Разработка классических приложений .NET» и .NET 8.

## Как играть

- Игроки ходят по очереди, первым ходит **X**. Внизу рядом со словом «Ход:» показано, чей ход.
- Нажатие на пустую клетку ставит в неё знак, и клетка блокируется.
- Побеждает тот, кто собрал три своих знака в строку, столбец или по диагонали. Сверху появится «Игрок X выиграл!», остальные клетки заблокируются.
- Если заполнены все 9 клеток и победителя нет, будет «Ничья!».
- Кнопка **«начать заново»** очищает поле.

## Как устроен код (по шагам методички)

| Шаг | Что в коде |
| 4, 14 | В конструкторе `Form1()` очищаются `label2`, `label3` и вызывается `ResetGame()` |
| 5 | Переменные `current_player` (чей ход), `turn_count` (число ходов), `buttons` (массив 3×3) |
| 6 | `Disabled_btn()` блокирует все кнопки |
| 7–9 | `CheckRows()`, `CheckColumns()`, `CheckDiagonals()` проверяют строки, столбцы, диагонали |
| 10 | `CheckForWinner()` объединяет три проверки через `||` |
| 11 | `Button_Click` ставит X или O, проверяет победу или ничью, передаёт ход |
| 12–13 | `ResetGame()` сбрасывает игру, её же вызывает кнопка «начать заново» |

В методичке метод блокировки в одном месте назван `Dis_btn()`, а в другом `Disabled_btn()`. В проекте везде используется `Disabled_btn()`.

Элементы формы (9 клеток, надписи, кнопка) создаются кодом в методе `InitializeUi()`, поэтому в конструкторе Visual Studio они не видны. Работает это так же, как если бы вы расставили их мышью.
Данный метод я решил использовать исключительно в образовательных целях, так как увидел, что так можно сделать, и решил попробовать.
